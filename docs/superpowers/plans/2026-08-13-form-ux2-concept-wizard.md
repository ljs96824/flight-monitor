# UX 2.0 概念归一与单开向导 TDD 计划

## 1. 锁定契约

- 保留 `before_ux2.json`、七场景规范化夹具、当前上海—大阪邮件字节哈希和 API 台账哈希。
- 运行 UX 一期、UX 1.5、通知渠道、地点解析相关现有测试，确认起点。

## 2. 先写失败测试

- 新增概念注册表守卫：缺字段、重复字段、跨站归属均失败。
- 新增语义控件容器唯一性测试，先暴露 `business_start/business_end` 双表面。
- 新增时段规范控件与派生矩阵测试：共享/分方向、红眼、到达偏好、自定义窗口。
- 新增六站单开、面包屑状态属性、确认页锚点测试。
- 新增共享芯片表面测试：不存在预设按钮与⑤站输入并行的第二套表面。

## 3. 实现概念层

- 在 `form_structure.py` 增加 `CONCEPTS`、`validate_concepts()`、字段归属索引和站点摘要元数据。
- 提供纯函数把 UX2 时间规范值派生为旧 slot/window/policy 表单值。
- 保持旧 POST 不带 UX2 标记时走原解析，七夹具零变化。

## 4. 重构模板表面

- 合并会议时间双表面。
- 删除六组原始 slot 控件，增加统一时间偏好组与按方向展开。
- 把⑤站规范控件改为同一套芯片组件；预设区只回显，不创建平行 input。
- 确保⑥站是通知配置唯一表面。
- 用 `data-concept` 与 `CONCEPTS` 标识控件归属，给确认行加站点锚点。

## 5. 实现单开向导

- 桌面/移动端统一只展示当前站。
- 增加六站面包屑、完成/当前/未到状态和站摘要。
- 保留四站快速收尾和 `monitor_mode` 派生；编辑旧订阅只标记进阶站，不同时展开多站。

## 6. 回归验证

- 跑新增测试到绿。
- 跑七场景基线 diff、编辑幂等、price_hint/地点/通知回归。
- 跑 `scripts/snapshot_run.py --output after_ux2.json` 并对比前后。
- 跑两个收集器全量测试；复核 API 台账、observations 哈希和邮件字节哈希。
- 检查 `git diff --check`、限定文件 diff，提交独立 commit；不 push，公开 CI 状态如实标为待用户 push 后验证。
