# HasData 退役 TDD 计划

1. 为国际源策略、采集计划无 HasData、首轮/次轮声明、历史日格和一致度衰减补失败测试。
2. 在 `source_profiles.py` 增加退役元数据与按观测日派生期望源的纯函数。
3. 让 T 曲线和 provenance 的退化标记读取同一期望源函数，不改聚合统计。
4. 在通知 payload 增加计划退役上下文，并让数据来源区按新配置展示 OTA 主源。
5. 过滤计划退役源的故障措辞；历史 payload 无新字段时保持旧渲染。
6. 验证篮子旧允许列表可忽略已退役源，且生产计划不生成 HasData 请求。
7. 运行定向测试、双收集器、快照 diff、历史邮件复放与台账哈希核对。
